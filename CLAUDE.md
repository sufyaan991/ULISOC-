# ULISOC

Islamic Society website for the University of Leicester. Next.js on Vercel. Supabase setup is deferred; database-backed features
are currently disabled.
See DEPLOYMENT.md for deployment and data migration requirements.

## Git conventions

Do not add Claude or Anthropic attribution to any commit or pull request.
Specifically, never append `Co-Authored-By: Claude ...` trailers to commit
messages, and never append `Generated with Claude Code` to PR descriptions.
Commits are authored solely by the repository owner.
